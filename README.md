# LevelMates

A World of Warcraft: Forever guild addon. See which guildmates are online and where, match quests with them, and ask for a hand with elites.

Addon messages only. No combat data. Your position and quests are shared only if you turn it on.

Slash commands: `/lm` (board), `/lm help <text>`, `/lm cancel`, `/lm options`, `/lm debug`.

Not in v1 (planned): level/zone sorting and a level filter on the board, a keybinding, "could pick up" / "still needs" quest notices, a named map marker for help requests (v1 uses your map's user waypoint, which replaces your own pin), ending a help request when the asker groups with a helper, and a tooltip warning that asking for help shares your position once.

# LevelMates (es)

Addon de hermandad para World of Warcraft: Forever. Ve qué hermanos están conectados y dónde, empareja misiones con ellos y pide ayuda con los elites.

Solo mensajes de addon. Nada de combate. Tu posición y tus misiones solo se comparten si lo activas.

Comandos: `/lm` (tablón), `/lm ayuda <texto>`, `/lm cancelar`, `/lm opciones`, `/lm debug`.

Pendiente para después de v1: ordenar el tablón por nivel/zona y filtrar por nivel, atajo de teclado, avisos "podría coger" / "le falta" de misiones, marcador con nombre en el mapa para las peticiones de ayuda (v1 usa el punto de ruta del jugador, que sustituye al tuyo), cerrar la petición cuando el que pide entra en grupo con quien dijo "Voy", y un aviso en el botón de que pedir ayuda comparte tu posición una vez.

Licencia: MIT.
