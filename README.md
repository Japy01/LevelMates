# LevelMates

A World of Warcraft: Forever guild addon. See which guildmates are online and where, match quests with them, and ask for a hand with elites.

Addon messages only. No combat data. Your position and quests are shared only if you turn it on.

Slash commands: `/lm` (board), `/lm options`, `/lm debug`.

License: MIT.

# LevelMates (es)

Addon de hermandad para World of Warcraft: Forever. Ve qué hermanos están conectados y dónde, empareja misiones con ellos y pide ayuda con los elites.

Solo mensajes de addon. Nada de combate. Tu posición y tus misiones solo se comparten si lo activas.

Comandos: `/lm` (tablón), `/lm opciones`, `/lm debug`.

Licencia: MIT.
